# 发给同事的提示词（可直接转发）

对方不需要装任何技能，也不需要本机已有 Node/Python。把下面第一段发给同事，让他转给智能体即可。

---

## 一、发给同事的话（他自己看）

```
我给你一个现成的部署规范仓库，你让你的智能体照它做就行，不用装插件：
https://github.com/zhangdunlong/lan-portable-deploy

把下面的提示词整段发给你的智能体（CodeBuddy / Claude / ChatGPT 都行），
把「项目路径」换成你自己的项目目录。
```

## 二、发给智能体的提示词（复制这段）

```
读取（或 clone）https://github.com/zhangdunlong/lan-portable-deploy 的 SKILL.md 与 references/ 全篇，
按其中的规范把我的项目改造成「U 盘拷到任意 Windows 电脑，双击就能跑，并在局域网用 80 端口提供服务」的形态。

项目路径：<填你的项目绝对路径>
输出目录：先问我要放哪（桌面 / 项目同级 / U 盘），不要自己决定

要求：
1. 先体检，逐条列出不满足项（绑定地址 0.0.0.0 / 端口 80 / /api/version / 数据目录独立 / 依赖情况），
   等我确认后再改源码
2. 打包必须自带运行时，目标机不装 Node/Python 也能跑
3. 业务数据目录不许打进包，升级覆盖代码时不能碰数据
4. 交付前自证：/api/version 能返回版本、首页 200、用本机局域网 IP（不是 127.0.0.1）也能访问
5. 最后告诉我：产物路径、本机与局域网访问地址、防火墙怎么放行、怎么停止和开机自启

如果 GitHub 打不开（国内常见），用镜像下载同一个仓库再读：
https://gh-proxy.com/https://github.com/zhangdunlong/lan-portable-deploy/archive/refs/heads/main.zip
```

## 三、对方智能体读不到网页时的兜底

若它既不能联网也不能 clone（内网模型、纯对话框），改用
[通用智能体提示词.md](通用智能体提示词.md) 里的**附录：内联长版**，规范已全部内联，不需要读仓库。

## 四、几句说明（可附在消息末尾）

- 产物体积约 80~90 MB，因为**自带 Node 运行时**（约 83 MB）——这是"目标机免安装"的前提
- 拷 U 盘时把整个文件夹拷过去就行，双击 `启动.bat`；想单文件传输就用 `部署包/` 里的一键升级 `.bat`
- 别的电脑打不开，九成是防火墙：右键 `防火墙放行.bat` → 以管理员身份运行
- 80 端口被占用时，`启动.bat` 会列出占用进程并允许回车改用 8080（届时局域网访问要带 `:8080`）
