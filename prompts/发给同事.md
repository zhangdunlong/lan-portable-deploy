# 发给同事的提示词（可直接转发）

对方不需要装技能，也不需要本机已有 Node/Python。**提示词只有几行**——细节由仓库里的规范负责，规范会自己问他三件事。

---

## 一、发给同事本人的话

```
给你一个部署规范仓库，让你的智能体照它做就行，不用装插件：
https://github.com/zhangdunlong/lan-portable-deploy

把下面这段发给智能体，它自己会问你项目、放哪、端口：
```

## 二、发给智能体的提示词（复制这三行）

```
读取 https://github.com/zhangdunlong/lan-portable-deploy 的 SKILL.md，按「第 0 步」先问我 3 个问题
（哪个项目 / 输出到哪 / 端口），然后照它的步骤执行：
把项目改造成「U 盘拷到任意 Windows 电脑双击就能跑、局域网用 80 端口提供服务」的形态。
```

它应该会问：**① 打包哪个项目 ② 输出到哪个目录 ③ 端口要不要改（默认 80）**。
若它没问就自己决定了，回一句：`按 SKILL.md 第 0 步先问我，别自己定。`

## 三、GitHub 打不开时

国内网络常拦 `github.com`。给它镜像地址，内容完全一致：

```
https://gh-proxy.com/https://github.com/zhangdunlong/lan-portable-deploy/archive/refs/heads/main.zip
```

如果它既不能联网也不能下载，改用本目录 [通用智能体提示词.md](通用智能体提示词.md) 的
**附录：内联长版**——规范全部内联，不依赖读仓库。

## 四、可选：附在消息末尾的说明

- 产物约 80~90 MB，因为自带 Node 运行时（83 MB）——这是"目标机免安装"的前提
- 拷 U 盘时把整个文件夹拷过去，双击 `启动.bat`；想单文件传输就用 `部署包\` 里的一键升级 `.bat`
- 别的电脑打不开，九成是防火墙：右键 `防火墙放行.bat` → 以管理员身份运行
- 80 端口被占时 `启动.bat` 会列出占用进程，允许回车改用 8080（届时局域网地址要带 `:8080`）
