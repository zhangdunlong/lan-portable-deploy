# 通用智能体提示词（自包含）

把下面整段复制给任何智能体（CodeBuddy / Claude / ChatGPT / Operit 等）。它不依赖本仓库是否被安装成技能，规范已内联，只需改三个占位符。

---

```
【任务】把指定项目打包成「普通 Windows 电脑免安装、双击即跑、局域网可访问（默认 80 端口）」的部署形态。

项目路径：<填绝对路径，例如 D:\my-app>
项目名：<填显示名，例如 车间看板>
运行时：<node 或 python>

【第一步：先体检，不要直接开始写文件】
检查并逐条报告：
1) 监听地址是否绑 0.0.0.0（绑 127.0.0.1 或 localhost = 局域网访问不到，必须改）
2) 端口是否从环境变量读（PORT），默认值是否为 80
3) 是否提供 /api/version，返回 {"version":"vX.Y.Z"}
4) 业务数据是否在独立目录（如 data/），与代码分离
5) 是否有第三方依赖、能否用语言内置模块替代
把不满足的项连同「需要改哪个文件、怎么改」一起告诉我，等我确认后再动源码。

【硬性约束（违反即返工）】
· 数据目录（data/ 等）绝不进部署包；升级覆盖代码时不得触碰数据
· .bat 必须 GBK 编码 + CRLF 换行（cmd 按 ANSI 解码，UTF-8 会中文乱码）；文件内先写 chcp 936
· .ps1 必须 UTF-8 带 BOM，且只能有一个 BOM（Windows PowerShell 5.1 靠 BOM 认 UTF-8，缺了会整段解析失败）
· 单文件自解压 .bat：base64 数据段之前必须有 exit /b 0，否则 cmd 会把 base64 逐行当命令执行并刷屏
· 版本号只允许一个来源（入口文件的 APP_VERSION），打包脚本只读不写
· 停止服务按端口定位进程，禁止 taskkill /f /im node.exe（会误杀同机其他程序）

【80 端口的正确处理】
· 默认 80：局域网其他设备只输 http://本机IP/ 即可
· 启动脚本必须先探测 80 是否被占用：被占用时列出占用进程（PID + 进程名），允许用户改用 8080
· 无论实际用哪个端口，都写入 _port.txt；停止脚本与升级脚本都要读它
  （不记录会导致「升级提示成功、版本号却没变」，甚至按错误端口误杀进程）
· 提示用户：彻底拿回 80 用管理员执行 net stop http；查占用用 netstat -ano | findstr :80

【产物结构（照此生成）】
<输出目录>/
├── <项目名>/                     ← 安装目录，双击 启动.bat 即可运行
│   ├── <入口文件>  <静态目录>/  data/(空)
│   ├── runtime/                  ← 便携运行时，实现目标机零安装
│   ├── 启动.bat                  ← 选运行时 → 查端口 → 写 _port.txt → 隐藏启动 → 开浏览器
│   ├── 停止.bat                  ← 写 _stop.flag → 停守护 → 停服务 → 清标志
│   ├── 防火墙放行.bat            ← 管理员运行，放行入站端口 + 程序
│   ├── 开机自启.bat              ← 启动文件夹快捷方式，再点一次取消
│   ├── watchdog.js               ← 零依赖守护：崩溃 2 秒后重启、日志 5MB 轮转、
│   │                               10 分钟内崩 20 次则写 _崩溃过多.txt 并止损
│   ├── setup.ps1                 ← 安装/升级引擎
│   ├── version.txt  安装说明.txt
└── 部署包/
    ├── <项目名>_升级包_v<版本>_<日期>.zip
    └── <项目名>_一键升级_v<版本>_<日期>.bat   ← 单文件自解压，拷过去双击即装

【安装/升级引擎必须做到】
① 自动定位安装目录：注册表记录 → 包内目录 → 常见位置扫描（打分：有 runtime +5、有数据文件 +4、有入口 +1）→ 弹框手选；
   临时目录（%TEMP%）里的路径一律不作候选，否则会把自己当安装目录，Copy-Item 报 "with itself"
② 备份现有入口与静态目录到 _升级备份_<时间戳>/，只保留最近 3 份
③ 按端口停服（端口取自 _port.txt）
④ 覆盖：入口文件直接换；静态目录先拷成 <目录>.__new__ 再原子改名，避免拷一半把站点搞坏
⑤ 重新拉起服务（经过隐藏启动脚本，保住端口环境变量）
⑥ 轮询 /api/version 校验版本一致；不一致要提示，不能当成功
⑦ 任何一步失败自动回滚到升级前并重启旧版本
⑧ 注册表记住安装位置，下次可全自动定位

【稳定性要求】
watchdog 必须满足三条：崩溃自动重启、日志落盘轮转、能干净停机（收到 _stop.flag 后停子进程并退出，不得把服务又拉起来）。
若运行时是 Python，说明 watchdog.js 不适用，给出降级方案（例如由 bat 循环守护），不要假装支持。

【交付前必须自证，并把结果贴出来】
1) 构建脚本自检：结构完整、.bat 是合法 GBK+CRLF、.ps1 只有单个 BOM、zip 内不含 data/、
   自解压 payload 能还原出与原 zip 逐字节一致的字节、无未替换的模板占位符
2) 真跑一次：启动安装目录里的服务，用 curl 验证 /api/version 返回版本、首页返回 200
3) 局域网可达：用本机局域网 IP（不是 127.0.0.1）curl 一次，返回 200
4) 守护有效：杀掉服务进程，观察 2~3 秒内是否自动换新 PID 恢复
5) 最后给我：产物路径、本机访问地址、局域网访问地址、防火墙放行方法、如何停止/开机自启

【如果环境限制导致某项做不到】
直接说明哪一项没做到、原因是什么、有什么替代方案，不要用「已完成」糊过去。
```

## 使用要点

- 只改三处：`项目路径`、`项目名`、`运行时`
- **只想要评估**：删掉「第一步」之后的内容，改成 `只做第一步体检，不要写任何文件，也不要改源码。`
- **目标智能体不能执行命令**（纯对话模型）：在末尾加
  `你无法执行命令，请直接输出全部文件的完整内容，按上面结构给出每个文件的路径与代码。`
- **为什么要内联这么多规范**：通用智能体在三个地方几乎必然出错 —— `.bat` 写成 UTF-8（中文乱码）、
  `.ps1` 不带 BOM（PowerShell 5.1 解析失败）、把 `data/` 一起打进包（升级冲掉业务数据）。
  这三条写进提示词，比事后返工便宜得多。
