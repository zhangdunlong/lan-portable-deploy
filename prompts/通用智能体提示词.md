# 通用智能体提示词

规范写在仓库里，提示词只负责"指路 + 让它按规范提问"。**不要**把规范复述进提示词。

## 一、标准版（推荐，两行）

```
读取 https://github.com/zhangdunlong/lan-portable-deploy 的 SKILL.md，按「第 0 步」先问我 3 个问题
（哪个项目 / 输出到哪 / 端口），然后照它的步骤执行：
把项目改造成「U 盘拷到任意 Windows 电脑双击就能跑、局域网用 80 端口提供服务」的形态。
```

第 0 步已经把提问规则写死了：项目默认当前、输出目录必须问、其余一律按默认生成。
所以提示词不需要再罗列要求，写多了反而和规范打架。

## 二、极短版（一句话）

```
按 https://github.com/zhangdunlong/lan-portable-deploy 的 SKILL.md，把当前项目做成 U 盘可用的局域网 80 端口部署包。
```

## 三、国内网络打不开 GitHub 时

给它镜像地址，内容一致：

```
https://gh-proxy.com/https://github.com/zhangdunlong/lan-portable-deploy/archive/refs/heads/main.zip
```

或让它抓原始文件（`raw.githubusercontent.com` 常被拦，前面加 `https://gh-proxy.com/`）：

```
https://raw.githubusercontent.com/zhangdunlong/lan-portable-deploy/main/SKILL.md
https://raw.githubusercontent.com/zhangdunlong/lan-portable-deploy/main/references/lan-readiness.md
https://raw.githubusercontent.com/zhangdunlong/lan-portable-deploy/main/references/windows-encoding.md
```

## 四、能执行命令的环境

```
git clone git@github.com:zhangdunlong/lan-portable-deploy.git   # SSH 通常比 HTTPS 通
按其中的 SKILL.md 执行；模板直接用仓库 assets/，不要自己重写。
```

## 附录：内联长版（智能体完全读不到仓库时才用）

用于内网模型、纯对话框、禁网环境。把下面整段贴进去。

```
【任务】把指定项目打包成「普通 Windows 电脑免安装、双击即跑、局域网可访问（默认 80 端口）」的部署形态。

先问我三件事，不要自己决定：① 打包哪个项目 ② 输出到哪个目录（给桌面/项目同级/自填三个候选）
③ 端口是否改（默认 80）。其余按默认执行，不要再问。

【第一步：先体检，不要直接写文件】
逐条报告：监听地址是否 0.0.0.0（绑 127.0.0.1 则局域网访问不到）、端口是否读环境变量且默认 80、
是否有 /api/version、业务数据是否在独立目录、有无第三方依赖。列出不满足项与改法，等我确认后再改源码。

【硬性约束】
· 数据目录不进包；升级覆盖代码时不得触碰数据
· .bat 必须 GBK + CRLF，开头 chcp 936（UTF-8 会中文乱码）
· .ps1 必须 UTF-8 带 BOM 且只有一个 BOM（PowerShell 5.1 靠 BOM 认 UTF-8）
· 单文件自解压 .bat：base64 段前必须有 exit /b 0，否则 cmd 会把数据当命令刷屏
· 版本号只有一个来源（入口文件 APP_VERSION），打包脚本只读不写
· 停服务按端口定位进程，禁止 taskkill /f /im node.exe

【产物】
<输出目录>/<项目名>/     安装目录：入口 + 静态目录 + data(空) + runtime/ +
                        启动.bat 停止.bat 防火墙放行.bat 开机自启.bat watchdog.js setup.ps1 version.txt 安装说明.txt
<输出目录>/部署包/        <项目名>_升级包_v<版本>_<日期>.zip
                        <项目名>_一键升级_v<版本>_<日期>.bat（单文件自解压）

【80 端口】默认 80，局域网只输 http://本机IP/；被占用时列出占用进程并允许改用 8080；
实际端口写入 _port.txt，停止与升级脚本都读它（否则会"升级成功但版本没变"）。

【运行时】默认自带（目标机零安装）；找不到就直接说明并提供 --runtime-exe 方案，不要静默降级。

【交付前自证】结构/编码/BOM/无 data 泄漏/自解压还原一致；真跑一次验证 /api/version 与首页 200；
用局域网 IP 再验一次；杀掉进程验证 2~3 秒自动恢复。最后给产物路径、访问地址、防火墙放行方法。

【做不到就直说】哪项没做到、原因、替代方案，不要用「已完成」糊过去。
```
