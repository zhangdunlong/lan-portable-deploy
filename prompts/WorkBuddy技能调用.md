# WorkBuddy 技能调用提示词

装好本技能后（`~/.workbuddy/skills/lan-portable-deploy/`），提示词只需要一句——**问什么、要哪些文件，都由技能的第 0 步负责**。

## 一句话（默认就用这个）

```
用 lan-portable-deploy，把当前项目打包成「拷 U 盘、到别的电脑双击就能跑」的局域网部署包。
```

技能会自己问你三件事：**哪个项目**（默认当前）、**输出到哪**（必问）、**端口**（默认 80）；
其余（运行时、zip、一键升级脚本、看门狗、防火墙、开机自启）全部按默认生成，不再打扰你。

## 常见补充（想改默认值时加一句）

| 想改什么 | 加这句 |
|---|---|
| 换项目 | `不是当前项目，打包 D:\另一个项目` |
| 指定输出位置 | `产物放 D:\部署\车间看板` |
| 换端口 | `用 8080` |
| 只要体检 | `先只体检，别改文件、别打包` |
| 目标机已装 Node，想减小体积 | `不用带运行时` |
| 只要升级包 | `出升级包就行，不动现有部署` |

## 纯静态站点 / Python 项目

```
用 lan-portable-deploy 打包当前项目（纯静态站，入口 index.html）。
```

```
用 lan-portable-deploy 打包当前项目（Python，入口 app.py）。注意 Python 用不了 watchdog.js，
按技能文档里的降级方案处理并说明。
```

## 触发要点

- 直接点名 `lan-portable-deploy`，比描述意图可靠
- **不必**在提示词里写端口、目录、编码要求 —— 这些已写死在技能里，写多了反而会和技能打架
